# Интеграция с производственным календарём

## Описание

Как администратор клиники, я хочу чтобы при добавлении рабочего расписания ветеринаров автоматически учитывались государственные праздники, чтобы не создавать рабочие смены в нерабочие дни.

## Бизнес-контекст

При ручном добавлении элементов расписания администратором система должна предупреждать о том, что выбранная дата является праздничным днём. Если, например, администратор пытается добавить рабочую смену на 1 января, система должна проверить эту дату по производственному календарю и отклонить добавление с соответствующим сообщением. Чтобы это работало, система должна получать актуальный список праздничных дней.

Источником данных о праздниках является сервис **xmlcalendar.ru**, предоставляющий производственный календарь России в машиночитаемом формате.

## Термины

| Термин                       | Определение                                                                      |
|------------------------------|----------------------------------------------------------------------------------|
| **Праздничный день**         | День, объявленный нерабочим в соответствии с производственным календарём России  |
| **Производственный календарь** | Официальный перечень рабочих, выходных и праздничных дней на год               |
| **xmlcalendar.ru**           | Внешний сервис, предоставляющий производственный календарь через API             |

## Требования

### Получение праздничных дней

- Система запрашивает производственный календарь у сервиса xmlcalendar.ru для нужного года.
- Список праздничных дней кэшируется на стороне системы — повторные запросы за один и тот же год не должны обращаться к внешнему сервису.
- Кэш обновляется не чаще одного раза в сутки, чтобы учитывать возможные изменения в официальном календаре.
- Если внешний сервис недоступен и кэша нет — генерация расписания невозможна; система возвращает ошибку с сообщением о недоступности календаря.
- Если внешний сервис недоступен, но кэш есть — используются кэшированные данные.

### Учёт праздников при добавлении элементов расписания

- При ручном добавлении элемента расписания система проверяет указанную дату на наличие в списке праздников.
- Если дата является праздничной — система отклоняет добавление и возвращает ошибку с сообщением о том, что выбранный день является праздничным.
- Правило применяется ко всем добавляемым элементам расписания независимо от ветеринара.

## Ограничения и допущения

- Интеграция покрывает только Россию; производственные календари других стран не поддерживаются.
- Перенос рабочих дней (когда выходной переносится на будний) в рамках данной задачи не учитывается — учитываются только нерабочие праздничные дни.
- Изменение праздничного статуса дня не влияет на уже добавленные элементы расписания — только на новые.

## Пользовательские сценарии

### Сценарий 1: Добавление элемента расписания на праздничный день

**Дано:** 1 мая (четверг) является праздничным днём  
**Когда:** Администратор пытается вручную добавить рабочую смену ветеринару Иванову на 1 мая  
**Тогда:** Система отклоняет добавление и возвращает ошибку с сообщением о том, что 1 мая является праздничным днём

### Сценарий 2: Добавление при недоступном сервисе без кэша

**Дано:** Сервис xmlcalendar.ru недоступен; в кэше нет данных на запрашиваемый год  
**Когда:** Администратор пытается добавить элемент расписания  
**Тогда:** Система возвращает ошибку с сообщением о невозможности получить производственный календарь

### Сценарий 3: Добавление при недоступном сервисе с устаревшим кэшем

**Дано:** Сервис xmlcalendar.ru недоступен; в кэше есть данные за нужный год  
**Когда:** Администратор пытается добавить элемент расписания  
**Тогда:** Система использует кэшированные данные и выполняет проверку; администратор получает предупреждение, что используются кэшированные данные

## API сервиса xmlcalendar.ru

### Endpoints

| Метод | URL                                                    | Описание                                                          |
|-------|--------------------------------------------------------|-------------------------------------------------------------------|
| GET   | `https://xmlcalendar.ru/data/ru/{year}/calendar.xml`   | Производственный календарь России за указанный год в формате XML  |

**Параметры пути:**

| Параметр | Тип                 | Описание                                                  |
|----------|---------------------|-----------------------------------------------------------|
| `year`   | Целое число (YYYY)  | Год, за который запрашивается календарь, например `2025`  |

### Структура ответа (XML)

Сервис возвращает XML-документ. Праздничные и нерабочие дни представлены элементами `<day>`:

```xml
<calendar>
  <days>
    <day d="01.01" t="1"/>  <!-- праздник -->
    <day d="01.02" t="2"/>  <!-- перенесённый рабочий день -->
    ...
  </days>
</calendar>
```

**Поля элемента `<day>`:**

| Атрибут | Тип                | Описание                                                              |
|---------|--------------------|-----------------------------------------------------------------------|
| `d`     | Строка (MM.dd)     | Дата в формате месяц.день, например `01.01` — 1 января               |
| `t`     | Целое число        | Тип дня: `1` — праздничный/нерабочий, `2` — перенесённый рабочий день |

Для проверки при добавлении элементов расписания используются только дни с `t=1`.
